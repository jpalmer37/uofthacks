# UofT Hacks 2021 submission

> **Archived hackathon repository.** This team project is preserved as a historical snapshot from UofT Hacks 2021. It is no longer maintained and is not presented as current production work.

## Project Context

The repository contains the source and visual assets for a Ren'Py narrative-game prototype created during the hackathon. The limited event timeline shaped its scope and implementation quality.

## Ownership and Attribution

This was shared hackathon work. John Palmer participated in the project, but the repository does not provide a complete contribution ledger and should not be read as a claim of sole authorship. Ren'Py and bundled framework assets retain their own attribution and licensing terms.

## Preservation Changes

The current tree excludes generated bytecode, runtime caches, local save games, log files, and crash traces. Human-authored Ren'Py source and project assets remain so the original submission can still be understood.

## Limitations

- The prototype has not been tested with current Ren'Py releases.
- It is not packaged as a distributable game.
- No license is granted by this repository; seek permission from the relevant contributors and asset owners before reuse.
